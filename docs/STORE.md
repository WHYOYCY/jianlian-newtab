```
「简练首页」把新标签页变成一张干净、有质感的仪表板。

▍液态玻璃视觉
卡片与搜索框采用多层内阴影 + 边缘反光模拟玻璃厚度，鼠标划过时卡片会有跟随光斑与轻微 3D 倾斜；

· 天气：自动定位或手动城市，显示温度、天气与风速，点击卡片即可刷新（数据来自 Open-Meteo，免费无需密钥）

不收集任何数据，没有统计与埋点，也没有自建服务器。所有配置只存在你自己的浏览器里；
唯一的对外请求是天气数据（只发送经纬度或城市名）。

▍可扩展
```

## 权限说明（审核必填）

Chrome Web Store 要求逐条说明权限用途，可直接使用：

| 权限 | 申请文案 |
|------|---------|
| `storage` | 用于保存用户自己的新标签页配置（卡片布局、背景、主题、搜索偏好）以及图标/天气缓存。数据仅保存在用户本地浏览器中。 |
| `history` | 用于在「历史记录」小组件中展示用户最近访问过的网页，方便一键回访。仅读取、仅本地渲染，不会上传到任何服务器。 |
| `geolocation` | 用于「天气」小组件的自动定位模式，将经纬度发送给 Open-Meteo 以获取当地天气。用户也可以在组件设置里改为手动输入城市，此时不会使用定位。 |
| 主机权限 `api.open-meteo.com` | 获取天气数据（免费开放 API，无需密钥）。 |
| 主机权限 `geocoding-api.open-meteo.com` | 用户手动输入城市名时，将其转换为经纬度。 |
| 主机权限 `api.bigdatacloud.net` | 自动定位时把经纬度反查为城市名，用于在天气卡片上显示所在地。 |

补充说明（放在「其他说明」栏）：

```
本扩展会在用户访问的网站上抓取站点图标（favicon / apple-touch-icon）用于快捷网址卡片显示，
这些请求是浏览器正常的图片加载请求，不携带用户身份信息，抓取结果缓存在本地。
```

## 隐私政策（必填字段）

商店要求提供隐私政策链接。可按下面内容建一个 `PRIVACY.md` 或发布为 GitHub Pages 页面：

```
# 隐私政策 · 简练首页

最后更新：2026-09-13

简练首页不收集、不存储、不传输任何个人数据。

1. 数据存储
所有配置（卡片布局、背景、主题、搜索偏好）保存在用户浏览器的 chrome.storage 中，
分为本机存储（storage.local）与可选的云端同步（storage.sync，由浏览器厂商加密同步）。
开发者无法访问这些数据。

2. 网络请求
本扩展仅发起以下网络请求：
- 天气数据（api.open-meteo.com）：发送经纬度（自动定位模式）或城市名（手动模式）
- 城市反查（api.bigdatacloud.net）：发送经纬度以获取城市名称
- 网站图标（各网站自身的 favicon 地址）：用于显示快捷网址卡片的图标

以上请求均不包含用户标识、不用于追踪、不发送给开发者一方。

3. 权限用途
- storage：保存配置与缓存
- history：在「历史记录」组件中读取并展示最近访问（仅本地渲染）
- geolocation：天气组件的自动定位（可在组件内改为手动城市）

4. 第三方
本扩展不含任何分析、广告或统计 SDK。

5. 联系方式
如有疑问，请在项目仓库提交 issue：https://github.com/WHYOYCY/jianlian-newtab/issues
```

## ⚠️ 上架流程（需要你在浏览器里操作）

1. 注册开发者账号：https://chrome.google.com/webstore/devconsole （一次性 **$5** 注册费，需信用卡）
2. 点「新增项目」→ 上传打包好的 zip（见下）
3. 填写商店信息：把上面的「简短说明」「详细说明」「权限说明」「隐私政策」分别粘进去
4. 上传 5 张截图 + 商店图标（128×128，仓库 `icons/icon128.png` 可直接用）
5. 填写「单一用途说明」：一句话概括，例如
   `提供一个可自定义的液态玻璃风格新标签页，包含搜索、快捷网址与若干小组件。`
6. 提交审核（通常 1~3 个工作日；首版审核可能更久）

> Edge 加载项商店（https://partner.microsoft.com/dashboard/microsoftedge）流程类似，**免费**，
> 且可以直接复用同一个 zip 包，审核通常更快。

## 打包 zip

扩展的运行文件只有下面这些（不含文档、测试、图标生成脚本）：

```
manifest.json  newtab.html  newtab.js
js/core.js  js/icons.js  js/presets.js  js/widgets/*.js
icons/icon16.png  icons/icon32.png  icons/icon48.png  icons/icon128.png
```

打包命令（在项目根目录，会自动按 `manifest.json` 的版本号命名）：

```bash
npm run zip        # 产物：dist/jianlian-newtab-<版本>.zip
```
